# Scripts Reference

## falcon CLI (preferred)

All ops run through `falcon` — see [`../../../../ops/docs/commands.md`](../../../../ops/docs/commands.md).

## backend/scripts/

| Script | Purpose |
|---|---|
| `run-tests.sh` | `mops install` + `dfx build app` |

Run:

```bash
cd backend && bash scripts/run-tests.sh
# or from root:
falcon b:test --local
```

## ops/

| Path | Purpose |
|---|---|
| `ops/falcon` | Global CLI entry |
| `ops/install.sh` | Link `falcon` to `~/.local/bin` |
| `ops/make-feature.sh` | `falcon m:f <Name>` scaffold |
| `ops/pkg-*.sh` | Hub package install/list/push |
| `ops/scripts/setup-init.sh` | `falcon s:init` |
| `ops/scripts/canister-call.sh` | `falcon c:call` |

## Templates

`ops/templates/feature/` — files generated by `falcon m:f <Name>`.
